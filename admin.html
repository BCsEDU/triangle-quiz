⚙️ 雲端資料庫與同步設定

讓全班所有學生的 iPad 在點擊送出後，能自動即時彙整到同一個雲端資料庫！

點我查看 Google 試算表 3 步驟串接教學（超簡單）
  1. 開啟一個空白 Google 試算表，點選「擴充功能」→「Apps Script」。
  2. 把下面的程式碼複製並貼上，覆蓋原有內容：
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); if (sheet.getLastRow() === 0) { sheet.appendRow(["繳卷時間", "班級", "座號", "姓名", "得分", "答對題數", "作答詳細JSON"]); } sheet.appendRow([ new Date(), data.className, data.seatNumber, data.studentName, data.score, data.correctCount, JSON.stringify(data.questionResults) ]); return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON); }
  1. 點右上角「部署」→「新部署作業」→ 齒輪選擇「網頁應用程式」，將「誰可以存取」改為「任何人」，點「部署」後複製產生的網址貼回此處！

Firebase 控制台建立 Realtime Database 後，將 Rules 設為 ".read": true, ".write": true 即可跨所有學生 iPad 即時同步！
