# 國小四年級數學「三角形」iPad 測驗系統與錯題分析後台

本系統專為國小四年級學生（康軒版 第六單元 三角形・活動2「以邊分類三角形」）量身打造，支援學生使用個人 iPad 進行線上作答，送出後立即自動對答與解析，並配備強大的教師後台資料庫，即時統整全班錯題比例與診斷分析。

---

## 🌟 核心特色

1. **iPad 觸控最佳化**
   - 專為 iPad 螢幕尺寸與觸控習慣設計（大按鈕、防誤觸、支援橫向與直向操作）。
   - 填空題內建 `inputmode="numeric"`，iPad 自動彈出數字專用大鍵盤。
   - 題形圖示完全採用高解析度原生向量 SVG 繪製，在 iPad Retina 螢幕上清晰無失真。

2. **即時自動對答與解析**
   - 學生完成 11 題後點擊「送出批改」，系統立即計算總分並對答。
   - 每一題即時標記 ✅ 答對 或 ❌ 需訂正，並同時列出「學生答案」、「參考正解」與「詳細解題觀念解析」。

3. **教師後台資料庫與錯題比例看板 (`admin.html`)**
   - **各題錯題比例長條分佈圖**：以色彩區分高錯誤率題型（紅色 ≥50%、橘色 ≥25%、綠色 <25%）。
   - **錯題排行榜**：按錯誤率由高到低自動排序，幫助老師一眼看出教學盲點（例如 Q8 摺紙等腰、Q10 補角角度計算）。
   - **深入錯題診斷**：點選任一題號，立即展開查看全班常犯的錯誤答案分佈統計。
   - **全班成績與正誤矩陣總表**：可一鍵點擊檢視單一學生的完整考卷。
   - **一鍵匯出 Excel/CSV**：便於老師登錄成績與補救教學追蹤。
   - **內建一鍵模擬 28 人數據按鈕**：方便老師在電子白板或老師 iPad 上快速演示。

4. **雲端跨裝置即時同步（支援 Google 試算表 / Firebase）**
   - 學生於個人 iPad 送出作答後，資料自動同步至雲端資料庫。
   - 支援國小老師最熟悉的 **Google 試算表 (Google Apps Script API)**，免架設伺服器即可直接在試算表中自動紀錄每一位學生的繳卷時間、座號姓名與得分。

## 🚀 如何發布到 GitHub Pages

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如 `triangle-quiz`。
2. 將此目錄下的所有檔案（`index.html`、`admin.html`、`README.md`）上傳至該儲存庫的根目錄或 `main` 分支。
3. 進入 GitHub 儲存庫的 **Settings** → **Pages**。
4. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支，資料夾選擇 `/ (root)`，點擊 **Save**。
5. 約 1~2 分鐘後即可獲得測驗網址：
   - **學生測驗端**：`https://<你的GitHub帳號>.github.io/triangle-quiz/`
   - **教師管理後台**：`https://<你的GitHub帳號>.github.io/triangle-quiz/admin.html`
